# Product Context

BMChat exists to provide a Russian-first, rebranded universal messenger experience based on Delta Chat's mature decentralized messaging stack.

Problems to solve:
- Provide a consistent BMChat identity across desktop, Android, and iOS.
- Offer complete Russian localization, including onboarding, settings, error states, store text, and platform-specific permission prompts.
- Keep Delta Chat's existing messaging capabilities, including email/chatmail transport, encryption, multi-profile behavior, media, invites, and cross-platform clients.
- Allow appearance changes through themes or a structured brand configuration instead of hardcoded one-off edits.

User experience goals:
- The app should feel like BMChat/BroMoreChat, not a lightly renamed Delta Chat build.
- Russian users should not encounter untranslated English UI in normal flows.
- Platform behavior should remain native and predictable on Windows, Linux, macOS, Android, and iOS.
- Future upstream Delta Chat security and protocol updates should remain practical to merge.
