# Active Context

Current focus: BMChat is now an e-mail-first messenger that uses the user's VPS at `5.187.4.132` only for the invite landing page (`/i`), the Android update manifest+APK (`/update.json`, `/apk/`), and the Desktop update manifest (`/desktop-update.json`). All actual conversation traffic — including the new e-mail invitations and their auto-acceptance on the receiving side — flows over the user's own IMAP/SMTP server, fully encrypted via Autocrypt-driven SecureJoin. The Rust core (Rust 1.91.1, Android NDK r25c) generates invite links that point at `http://5.187.4.132/i#…`; the placeholder `i.bmchat.example` is retired and legacy hosts (`i.bmchat.example`, `i.delta.chat`) are still accepted on parse for back-compat. The in-app Android updater (`BMChatUpdater`) pulls `update.json`, verifies the SHA-256 of the downloaded APK, and installs it via `PackageInstaller`. The Electron main process now runs an analogous `bmchat-updater.ts` that polls `desktop-update.json` and offers a download dialog. Cleartext HTTP is whitelisted only for the VPS IP. The earlier UI guard layer in Java/TypeScript/Swift remains as a safety net for legacy QR codes generated by older builds.
