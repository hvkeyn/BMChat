What is BMChat?

BMChat / BroMoreChat is a free messenger for communication through email systems. It keeps familiar chat, group, attachment, and QR invite workflows while using decentralized email/chatmail infrastructure instead of a single central service.

How does BMChat work through email systems?

Messages are transported through existing email or chatmail servers. For users it behaves like a messenger: create a profile, add contacts, send messages, share files, record voice messages, and invite people with QR codes.

How do I create shared chats?

Press the new chat button and choose New Shared Chat. Set a name, add members, and send the first message. Other members will see the shared chat after that first message is sent.

How does BMChat protect messages?

BMChat inherits BMChat's secure messaging model: end-to-end encryption, QR contact verification, profile backups, and communication without depending on one provider. Exact behavior depends on the mail server and client version.

What is BMChat based on?

BMChat is a fork of BMChat and preserves required upstream attribution. Technical references to BMChat, chatmail, and core components may remain in licenses, developer documentation, and protocol-compatible internals.
