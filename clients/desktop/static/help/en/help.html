What is BMChat?

BMChat is an e-mail-first secure messenger. Every message travels through your own IMAP/SMTP mailbox, encrypted end-to-end with the OpenPGP-based Autocrypt standard. There is no centralised server holding your contact list, no Apple/Google account tied to your identity, and no third-party push notification service that can read your data.

  • End-to-end encryption is on by default for every conversation between BMChat users.
  • You bring your own mail server, so you fully decide where your data lives.
  • Group chats and direct messages share the same secure transport.
  • The app updates itself from our update server with a SHA-256-verified APK.

Setting up your first profile

On first launch you can either create a new chat profile or restore an existing one from a backup. To create a profile:

  1. Choose I have an e-mail account.
  2. Enter the address and password of an IMAP-capable mailbox you control.
  3. Tap Sign In. BMChat detects IMAP/SMTP settings automatically for most providers.
  4. Optionally, set a display name and avatar in Settings → My Profile.

If you prefer to start from a backup, choose I already have a profile on the welcome screen and follow the on-screen instructions.

Inviting people to chat

BMChat does not have a public directory. Each contact is added explicitly:

  • QR code: tap the QR icon in the upper right corner and ask the other person to scan it with their BMChat app.
  • Invite link: from the same screen, choose Copy or Share and send the link through any other private channel.
  • Direct e-mail: just write to a known address from inside BMChat. The first message becomes a contact request that the other side must accept.

As soon as both sides exchange one message, end-to-end encryption is established automatically and stays in place for every following message.

Groups

Groups in BMChat are secure: every member has the same rights and the entire member list is end-to-end encrypted.

  • Open the menu in the chat list and choose New group.
  • Pick a name, an optional avatar and the members.
  • Anyone in the group can later add or remove members, change the avatar or set disappearing-message timers.

Groups behave best with up to roughly 150 trusted contacts. Larger rooms are technically possible but get socially noisy quickly.

Using BMChat on several devices

Every device runs an independent copy of your profile. To synchronise them:

  1. On the existing device open Settings → Add Second Device and unlock if prompted.
  2. Make sure both devices are on the same Wi-Fi or local network.
  3. Install BMChat on the new device, choose Add as Second Device on the welcome screen and scan the QR code.
  4. Wait for the transfer to finish on both ends.

If Add Second Device is not available, use Settings → Chats → Export Backup on the source device and Restore from Backup on the destination one.

App updates

BMChat ships its own updater. The Android app polls http://5.187.4.132/update.json every few hours, downloads the new APK from the same host, verifies its SHA-256 fingerprint, and asks you to install it through the standard Android package installer. The desktop client follows the same model with desktop-update.json.

You can also force a check from Settings → Advanced → Check for updates now.

Storage and cache management

BMChat keeps a local cache of received attachments and the chat database. To inspect or clean it:

  • Open Settings → Storage and Data.
  • The donut chart shows total used space, evictable cache and free space.
  • You can clear individual categories (photos, video, voice, files, apps) or pick specific chats.
  • Auto-clean can drop messages older than a configurable threshold and keep cache size below a chosen limit.

Cleared local copies can usually be redownloaded from the mail server on demand. A separate «dangerous zone» lets you also delete messages from the IMAP server itself; that operation is irreversible and confirms with an explicit dialog.

Spam folder, all-folders sweep, classic e-mail

Some providers move legitimate chat traffic into the Spam or Junk folder. BMChat handles that for you:

  • By default, BMChat watches Inbox, Sent, your move-to folder and Spam/Junk, moves chat-shaped messages out of Spam and shows them as normal chats.
  • If your provider hides chat traffic in non-standard folders, enable Settings → Advanced → Scan all server folders. BMChat will periodically sweep every folder outside Trash for new chat messages. This costs more bandwidth and battery, so it is opt-in.
  • Plain e-mails from non-BMChat senders also appear in your chat list as classic-mail conversations marked with an envelope icon.

Notifications and battery

Reliable notifications on Android usually require the app to keep a small background connection alive. If new messages arrive only after you reopen BMChat, try the following in order:

  1. Settings → Notifications → Force Background Connection.
  2. Disable battery optimisation for BMChat in your phone’s system settings.
  3. Some Android vendors restrict background apps aggressively. See dontkillmyapp.com for vendor-specific tips.

End-to-end encryption

BMChat uses OpenPGP via the Autocrypt protocol. Keys are generated locally and never uploaded to a key server. As soon as you exchange one message with a contact, every following message between you is end-to-end encrypted, including attachments and metadata such as filenames.

In contact details you will see two fingerprints. If both devices display the same pair, the connection is verified. Adding contacts via QR-code or invite link gives you a verified channel from the start.

Mail sent to or from non-BMChat addresses is not end-to-end encrypted; such conversations are clearly marked with a small envelope icon next to messages.

Privacy

  • BMChat does not collect telemetry. There is no «send statistics» toggle that ships data to a third party.
  • Your IP address is visible only to the IMAP/SMTP server you log into. The BMChat update server only ever sees update-check requests, not message data.
  • Local cache, profile pictures and group state live on your device, not on a central server.
  • You can run a fresh profile against a throw-away mailbox at any time; nothing connects different profiles together.

Source code and reporting bugs

BMChat is free software. The source code lives at github.com/hvkeyn/BMChat. Bug reports and feature requests go to github.com/hvkeyn/BMChat/issues. When opening an issue please include the version number from Settings → About and, where relevant, an exported log file (Settings → Advanced → View log).
